# 🛒 장보기 타임어택

제한 시간 안에 장보기 목록의 물건을 정확한 수량만큼 담고 계산을 끝내는 마트 게임입니다.

## 바로 플레이하기

👉 https://hailey1220.github.io/Aiffel_My-game/

PC와 휴대폰 브라우저에서 모두 플레이할 수 있습니다.

## 게임 방법

위에서 내려다본 마트를 캐릭터가 직접 돌아다니며 장을 봅니다.

1. **방향키 / WASD**로 움직이거나, 지도에서 가고 싶은 곳을 **클릭·탭**하면 그곳까지 걸어가요.
2. 오른쪽 목록에 있는 상품 위를 **지나가면 자동으로 장바구니에 담겨요**. 2개가 필요하면 한 번 벗어났다가 다시 밟아요.
3. 목록에 없는 상품을 밟으면 **3초 감점**이에요.
4. 돌아다니는 **다른 손님**과 부딪히면 잠깐 멈춰요.
5. 다 담았으면 오른쪽 아래 **계산대**로 가면 단계 클리어!

단계가 올라갈수록 목록이 길어지고, 손님이 늘어나고, 시간은 짧아집니다. **매장 진열은 단계마다 바뀌고**, 3단계부터는 찾아야 할 상품의 노란 테두리 힌트가 사라져요.

## 로컬에서 실행

별도 설치 없이 `index.html` 파일을 브라우저로 열면 됩니다.
