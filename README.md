# 🛒 장보기 타임어택

제한 시간 안에 장보기 목록의 물건을 정확한 수량만큼 담고 계산을 끝내는 마트 게임입니다.

## 바로 플레이하기

👉 https://hailey1220.github.io/Aiffel_My-game/

PC와 휴대폰 브라우저에서 모두 플레이할 수 있습니다.

## 게임 방법

1. 오른쪽 영수증에 적힌 **꼭 사야 할 물건**을 정해진 수량만큼 담아요.
2. 위쪽 **통로 탭**을 눌러 코너(과일·채소, 음료·유제품, 정육·수산, 빵·과자, 생활용품)를 옮겨 다녀요.
3. 다 담았으면 **계산하기**를 눌러요. 빠진 물건이나 필요 없는 물건이 있으면 5초가 깎여요.
4. 남은 시간이 많을수록, 실수 없이 담을수록 점수가 올라가요.

단계가 올라갈수록 목록이 길어지고, 수량이 늘고, 시간은 짧아집니다. 3단계부터는 통로 힌트가 사라져요.

## 로컬에서 실행

별도 설치 없이 `index.html` 파일을 브라우저로 열면 됩니다.
