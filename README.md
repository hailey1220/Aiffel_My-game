## 🛒 장보기 타임어택

위에서 내려다본 마트를 캐릭터가 직접 돌아다니며 장을 봅니다.

1. **방향키 / WASD**로 움직이거나, 지도에서 가고 싶은 곳을 **클릭·탭**하면 그곳까지 걸어가요.
2. 목록에 있는 상품 위를 **지나가면 자동으로 담겨요**. 2개가 필요하면 한 번 벗어났다가 다시 밟아요.
3. 목록에 없는 상품을 밟으면 **3초 감점**, 돌아다니는 **다른 손님**과 부딪히면 잠깐 멈춰요.
4. 다 담았으면 오른쪽 아래 **계산대**로 가면 단계 클리어!

단계가 올라갈수록 목록이 길어지고 손님이 늘어나며, 매장 진열은 단계마다 바뀝니다.

## 👗 백스테이지 퀵체인지

패션쇼 백스테이지의 스태프가 되어, 런웨이에서 돌아온 모델에게 정해진 착장을 빠르게 입힙니다.

1. 모델이 피팅 자리에 서면 **룩 카드**(입혀야 할 옷 목록)가 보여요.
2. 상의·하의·아우터 행거, 신발장, 액세서리 테이블을 돌며 맞는 옷 위를 지나가 **손에 들어요** (최대 5벌, 누르면 되돌려놓기).
3. 옷을 들고 모델에게 다가가면 **저절로 입혀져요**. 룩 카드와 맞는지 확인하고 **Space**나 **Enter**(휴대폰은 **런웨이로** 버튼)로 내보내요.
4. 틀린 옷을 입혔거나 모델의 제한 시간이 끝나면 **목숨(♥) −1**. 세 개를 모두 잃으면 쇼가 중단돼요.

| 쇼 | 입힐 옷 | 모델 수 | 동시에 | 룩 카드 |
|---|---|---|---|---|
| 1 | 상의·하의·신발 | 3명 | 1명 | 계속 보임 |
| 2 | + 액세서리, 무늬 등장 | 4명 | 2명 | 계속 보임 |
| 3~ | + 아우터 | 5~6명 | 3명 | 도착 후 5초만 (다시 보기 −3초) |

색만 살짝 다르거나(빨강/분홍, 파랑/남색) 무늬만 다른 **비슷한 옷 함정**을 조심하세요.

## 새 게임 추가하기

새 게임은 새 폴더(예: `my-new-game/index.html`)로 추가하고, 맨 위 `index.html` 게임 목록에 카드를 하나 더 넣으면 됩니다. 기존 게임은 그대로 유지돼요.
